# Electronics Calculator

A scientific calculator Android app with advanced math functions.

## Features
- Basic operations: +, −, ×, ÷
- Scientific functions: **sin, cos, tan, log, ln**
- Factorial, percent, inverse
- Pi and e constants
- Power (x^y)
- Expression parsing with mXparser
- Material Design UI
